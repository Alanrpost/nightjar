# Nightjar

<p align="center">
  <img src="docs/logo.png" alt="Nightjar logo" width="220">
</p>

Минималистичный VPN-клиент для Windows: TUN-режим (весь трафик через один
защищённый туннель), kill switch, автозапуск, split tunneling по приложениям и сайтам.
Поддерживает **VLESS**, **Shadowsocks**, **Trojan**, **Hysteria2**, **TUIC** —
протокол определяется автоматически по ссылке подключения.

## Скачать

**[⬇ Скачать Nightjar-Setup.exe](https://github.com/Alanrpost/nightjar/releases/latest/download/Nightjar-Setup.exe)**
— Windows 10/11 (64-bit). Запустите установщик и следуйте подсказкам.

> При запуске установщика Windows может показать SmartScreen: «Windows
> защитила ваш компьютер» / «Неизвестный издатель». Это не вирус — просто
> exe не подписан платным сертификатом (проект бесплатный, без издателя).
> Нажмите **«Выполнить в любом случае»**.

## Как пользоваться

1. Скопируйте ссылку подключения (`vless://`, `ss://`, `trojan://`,
   `hysteria2://` или `tuic://`) в буфер обмена.
2. В приложении: **«Добавить конфигурацию» → «Конфигурация из буфера
   обмена»** (или через QR-код) — профиль появится в списке.
3. Выберите профиль и нажмите **«Подключиться»**. Зелёная точка — соединение
   активно.
4. Для отключения — та же кнопка или иконка в трее.

Приложение само запросит права администратора (нужны для TUN-адаптера) и
подчищает зависшие процессы после сбоев — перезагружать компьютер не нужно.

**Дополнительно:** kill switch, автозапуск с Windows, автопереподключение,
тест скорости и split tunneling по приложениям и сайтам настраиваются прямо в
интерфейсе.

## Логи

`%APPDATA%\vless-client\singbox.log` — если профиль не подключается.
