# VLESS Client (TUN mode, sing-box backend)

Минималистичный мультипротокольный клиент для Windows: импорт подключения из
буфера обмена или QR-кода (как в Happ), TUN-режим (весь трафик ноутбука через
прокси), но с надёжной очисткой сетевых настроек при остановке или крэше —
чтобы не требовалась перезагрузка.

Поддерживаемые протоколы — определяются автоматически по префиксу ссылки при
импорте, выбирать протокол вручную не нужно:

- **VLESS** (`vless://`) — включая Reality/Vision.
- **Shadowsocks** (`ss://`) — современный формат SIP002 и легаси с полностью
  закодированной ссылкой.
- **Trojan** (`trojan://`).
- **Hysteria2** (`hysteria2://` или `hy2://`).
- **TUIC** (`tuic://`).

## Подготовка окружения (один раз)

1. **Python 3.11+** — скачать с https://www.python.org/downloads/windows/ и при
   установке поставить галку "Add python.exe to PATH".

2. **sing-box** — скачать архив `sing-box-<version>-windows-amd64.zip` со страницы
   официальных релизов проекта SagerNet/sing-box на GitHub, извлечь из него
   `sing-box.exe` и положить в папку `bin/` рядом с этим README.

3. **wintun.dll** — драйвер виртуального адаптера (тот же, что использует
   WireGuard). Скачать с официального сайта wintun.net (раздел amd64) и положить
   `wintun.dll` в ту же папку `bin/`, рядом с `sing-box.exe`.

4. Установить зависимости Python:

   ```
   pip install -r requirements.txt
   ```

## Запуск

```
python -m app.main
```

Приложение само запросит права администратора (UAC) — они нужны для создания
TUN-адаптера и системных маршрутов. Без прав администратора TUN-режим на Windows
не работает.

При запуске приложение сначала проверяет, не осталось ли висящего процесса
`sing-box.exe` или TUN-адаптера от прошлого аварийного завершения, и подчищает их
автоматически — поэтому перезагрузка ноутбука больше не требуется.

## Использование

1. Скопировать ссылку подключения (`vless://...`, `ss://...`, `trojan://...`,
   `hysteria2://...` или `tuic://...`) в буфер обмена.
2. Нажать **"Добавить конфигурацию"** → **"Конфигурация из буфера обмена"** —
   протокол определится автоматически, профиль появится в списке. Там же —
   **"Конфигурация из QR"** (картинка с QR-кодом) и **"Добавить вручную"** (форма
   с нуля, с выбором протокола).
3. Выбрать профиль (чекбокс в строке) и нажать **"Подключиться"**. Зелёная точка
   и зелёная иконка в трее — соединение активно.
4. Чтобы отключиться — та же кнопка (теперь **"Отключиться"**) или через меню трея.

У каждого профиля в списке — кнопка-меню (три точки): **"Редактировать JSON"**
(сырой конфиг sing-box), **"Редактировать профиль"** (форма с полями, поля
меняются в зависимости от выбранного протокола), **"Удалить"** (с подтверждением).

Закрытие окна (крестик) сворачивает приложение в трей, соединение продолжает
работать. Полностью выйти — через пункт "Выход" в меню трея.

## Дополнительные функции

- **Kill switch** — чекбокс "Kill switch" (включён по умолчанию). Если туннель
  неожиданно обрывается, интернет блокируется полностью (через тот же TUN-адаптер,
  но с `route.final: "block"`) до восстановления соединения — вместо того, чтобы
  утечь в обычную сеть в открытую.
- **Автопереподключение** — при неожиданном обрыве приложение само пробует
  переподключиться с растущей задержкой (3с → 6с → 12с → 24с → 30с), пока либо не
  получится, либо вы не нажмёте "Отключиться" вручную.
- **Автозапуск с Windows** — чекбокс "Автозапуск с Windows". Регистрирует задачу в
  Планировщике заданий Windows (`schtasks`) с правами "Выполнять с наивысшими
  правами" — при следующих загрузках Windows приложение запускается без запроса
  UAC. Вместе с чекбоксом **"Подключаться при запуске"** приложение само
  восстановит последнее активное подключение.
- **Тест скорости** — кнопка "Тест скорости" (доступна когда подключено) —
  измеряет пинг/скачивание/загрузку через туннель (библиотека `speedtest-cli`,
  работает по сети Ookla).
- **Split tunneling по приложениям** — отдельная кнопка **"Split tunneling"** на
  главном экране (глобальная настройка, не привязана к конкретному профилю —
  применяется к любому активному подключению). Список `.exe`, трафик которых
  должен идти напрямую, минуя VPN (например, локальный принтер или NAS-клиент).
  Кнопка "Выбрать из процессов" показывает список всех запущенных программ для
  выбора без ручного ввода имён.

## Логи

`%APPDATA%\vless-client\singbox.log` — вывод процесса sing-box (полезно для
диагностики, если профиль не подключается).

## Структура проекта

```
app/
  profile_parser.py        # парсинг ссылок всех протоколов, автоопределение по префиксу
  singbox_config.py        # генерация JSON-конфига sing-box (свой outbound на протокол + blockall для kill switch)
  singbox_manager.py       # запуск/остановка/мониторинг процесса
  cleanup.py                # уборка осиротевшего процесса/адаптера при старте
  profile_store.py          # хранение профилей в %APPDATA%
  settings.py                # настройки приложения (kill switch, автоподключение, split tunneling)
  autostart.py                # регистрация задачи автозапуска в Планировщике
  stats.py                     # счётчики трафика через Clash API sing-box
  qr_import.py                  # распознавание ссылки из QR-кода
  edit_profile_dialog.py        # форма редактирования профиля (поля зависят от протокола)
  process_picker_dialog.py      # выбор процессов для split tunneling
  split_tunnel_dialog.py         # глобальная настройка split tunneling
  json_edit_dialog.py             # редактор сырого JSON-конфига профиля
  tray_app.py                      # GUI (трей + окно)
  main.py                          # точка входа, повышение прав
  assets/                           # SVG-иконки кнопок
bin/                                # сюда кладутся sing-box.exe и wintun.dll
tests/                               # юнит-тесты парсера
```
